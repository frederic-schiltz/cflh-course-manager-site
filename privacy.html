Privacy Policy

CFLH Course Manager

This Privacy Policy explains how CFLH Course Manager handles data.

1. Purpose of the application

CFLH Course Manager is a desktop application used to manage course-related administrative data, to send emails to course participants, and to read, organize, and manage incoming emails, including downloading attachments and updating the read/unread status of messages.

2. Data processed by the application

The application may process participant names, contact details, course-related administrative data, generated course documents such as certificates, and the content of emails accessed through Gmail, including sender and recipient addresses, subject, body, and attachments.

All such data is processed locally on the user’s computer.

3. Use of Google services

The application uses the Gmail API to send emails, read email content and attachments, and update the read/unread status of messages, based on actions explicitly initiated by the user.

Scopes used:
https://www.googleapis.com/auth/gmail.send
https://www.googleapis.com/auth/gmail.readonly
https://www.googleapis.com/auth/gmail.modify

The application does not:

  • permanently delete emails or bypass the Trash
  • send emails without explicit action by the user
  • store Gmail data on external servers
  • share Gmail data with third parties

4. Data storage

The application does not store personal data on external servers. Data remains on the user’s local system unless explicitly sent by email by the user.

5. Data sharing

No personal data is shared with third parties, except when emails are sent by the user through Gmail.

6. Security

The application uses Google OAuth 2.0 authentication for Gmail access. No Gmail password is stored by the application.
